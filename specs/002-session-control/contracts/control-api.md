# Contract: Control API

Paths are relative to `/api/m/:machineId` (or the `local` alias). Every `POST` passes the hub's `guard.ts` first: `Content-Type: application/json`, allowed `Origin` (missing refused), `X-C9view-Control: 1`, authenticated; any failure → 403. Every mutation also carries `X-C9view-Boot-Id` ([research R3](../research.md#r3-command-receipts)). Any mutation may get 409 `unknown-outcome`: a repeat after a node restart, a repeat of a command whose receipt expired (tombstone), or any new command once the boot's tombstone cap is reached; none of them acts. Bodies above 48 KiB → 413. Unknown project, session or request IDs → 404. With control off on the node, every route here → 404. Types in [data-model.md](../data-model.md).
