# Contract: CLI

| Command                                                              | PR   | Behaviour                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `c9view start [today's flags]`                                       | 6.0a | Hub + in-process node `local`; flags, defaults and behaviour unchanged.                                                                                                                                                                                                                    |
| `c9view hub [--no-local] [listener flags]`                           | 7b   | Hub; own machine as `local` unless `--no-local` (then no index, hooks reader or watcher). Refuses auth `none` with a paired remote node or a node with control, even with `C9VIEW_INSECURE_NO_AUTH=1`.                                                                                     |
| `c9view hub pair`                                                    | 7b   | Prints a one-time code valid 10 min.                                                                                                                                                                                                                                                       |
| `c9view hub machines list` / `revoke <id>`                           | 7c   | Lists paired machines; revoke deletes the key and closes the socket.                                                                                                                                                                                                                       |
| `c9view node --hub <url> [--name] [--listen] [--control] [--bypass]` | 7b   | Node with no port; `--listen` adds a hub-less listener with today's rules. With `C9VIEW_IN_CONTAINER=1`, `--control` and `--bypass` refuse with a pointer to the native install. Refuses to start if the state folder is wider than 0700 or the key wider than 0600, printing the `chmod`. |
| `c9view node pair --hub <url> --code <code> [--name <name>]`         | 7b   | Generates the key pair, pairs, writes `identity.json`.                                                                                                                                                                                                                                     |
| `c9view node install-service [--yes] [node flags]`                   | 7e   | Prints the systemd user unit (`~/.config/systemd/user/c9view-node.service`) or launchd plist (`~/Library/LaunchAgents/dev.c9view.node.plist`) and writes only after confirmation or `--yes`. Flags are baked in.                                                                           |
| `c9view node uninstall-service` / `service status`                   | 7e   | Removes only the file it wrote; status = installed, running, connected.                                                                                                                                                                                                                    |
| `c9view hooks status`                                                | 6.0d | Also reports the legacy events path when it exists.                                                                                                                                                                                                                                        |

Failed node connections name the likely cause: no route, TLS, Access login page, refused pairing. A revoked node logs "This machine was removed from the hub; pair it again."
